# Jen Li Kao Pixel Portfolio — Design Spec

日期：2026-09-24　狀態：待 review

## 目標

- 版面仿 **2001 年 Habbo Hotel 官網**（habbohotel.co.uk，2001-09 Wayback 存檔）：深灰底、置中、左欄堆疊面板 + 右側黑色側欄。畫風是 Habbo 像素風；**操作是一般網站**（捲動 + 錨點連結），不做遊戲式互動。
- 招募者在側欄一次看到所有區塊連結。
- 靜態網站，部署在 `https://kaojenli.github.io`。

> 2026-09-24 改版：原本「點房間家具開可拖曳視窗」的設計，依使用者回饋改成上述網站版面；房間保留為首頁插圖。
>
> 2026-09-30：Jen 的像素頭像從 About 移到首頁自我介紹右邊，做成歐式肖像畫：頭與肩膀、橢圓開口、鍍金畫框（斜接角、珠飾線腳、四角花飾、頂部貝殼），整張是一張像素圖（main.js `framedPortrait`）。手機版放在名字上方。
>
> 2026-09-30（二）：畫框改成胡桃木加細古金內框（不那麼金），置中在自我介紹右邊的空白；畫框上方加黃銅畫燈。右上角加亮／暗模式切換鍵（預設跟系統，選過會記住）；暗色像夜裡的美術館，畫燈往下打暖光、畫框下半沒入陰影。Jen 的髮型改成接近中分的小旁分、過肩自然捲、髮尾小波浪（avatar.js `HAIR.jen`）。
>
> 2026-09-30（三）：切換亮暗改成整頁淡入淡出（View Transitions，0.6 秒；不支援的瀏覽器直接切換）。畫燈的光重做成看得出光源：燈罩下緣發亮並有光暈、燈罩本身不受光、一道柔和光束從燈往下展開照在畫上並溢到牆上，離燈越遠越暗。
>
> 2026-09-30（四）：效能。場景任何變動都會讓瀏覽器重畫整個 SVG，原本一萬多個家具圖形讓每次重畫很貴。改成：不會動的家具按深度分段轉成裁切過的圖片（DOM 11,900 → 3,100；分段不跨整數深度，走動的人仍排在正確前後）；所有動畫（人物、走路、CSS 動畫）對齊同一個每秒 16 格的時鐘；場景不在畫面上時全部停住。載入時少畫看不到的過渡格，多邊形像素測試加快（像素結果逐格比對完全相同）。實測（headless Chrome，主執行緒忙碌）：看著場景時 41% → 約 11%，捲走時 45% → 約 6%，載入尖峰約 3 秒 → 約 2 秒。
>
> 2026-09-30（五）：練習場加兩個角色：烏龜 Sam（慢慢在草地上走，一格 1.4 秒）和 Snow girl（雪人，紅色蘇格蘭格紋圍巾與紅蝴蝶結，站在一小片雪上）。對話裡剩下的表情符號與顏文字全部改成純文字。
>
> 2026-09-30（六）：Sam 改成水藍色，可以爬遍整個一樓（練習場、人行道、咖啡店、玄關、客廳、駭客房；經咖啡店門進出但不會停在門口）。Snow girl 移到人行道上咖啡店門口附近（郵筒和路燈之間），不在投球的練習場。
>
> 2026-09-30（七）：側欄不再被截斷（不再限制高度、內部捲動）。客廳裡的 Jen 有自己的小日常（cabin.js `ROUTINES.jen`）：大多時候靜靜站著，偶爾眨兩下眼、眨單眼、左右張望、伸懶腰打哈欠、原地轉一圈、轉身看壁爐、拿咖啡喝兩口、先左右看看再偷吃餅乾（嚼一嚼再眨眼）。被點到時會先轉回來揮手。

> 2026-09-30（八）：首頁畫框裡的 Jen 也會動（main.js `portraitLife`）：同一套小日常的 11 格（靜止、眨眼、眨單眼、張望、喝咖啡、吃餅乾；不含舉手打哈欠，也不轉到背面）畫成一張長條圖，只切換 viewBox；reduced motion 時不動。

> 2026-09-30（九）：Jen 的背影改成長捲髮：從後面看頭髮垂過肩膀蓋住背（到肩胛骨下方），兩側有波浪、髮尾捲起，髮絲是一條條波浪線（avatar.js `HAIR.jen.backFall`，只在背面畫在毛衣上面）。

> 2026-09-30（十）：Jen 的瀏海改成八字瀏海：從分線往兩邊畫出兩道弧，到太陽穴時垂到眉毛高度，每道弧上緣有一條反光。所有人的頭髮改成有體積的畫法（avatar.js `hairTone`）：把頭當成一顆球，光從前上方來，頭頂有一道細細的反光弧，後腦和下方較暗；髮絲從頭頂（或分線）放射出去，長髮部分往下垂並帶一點波浪。深色頭髮最暗的顏色不會跟黑色描邊混在一起。Jen 背影的捲髮加上亮面，黑髮上也看得出波浪。

> 2026-10-01：聯絡方式只留一處：側欄的 Contact 卡。拿掉首頁介紹下的連結、About 裡的連結、最後的 Contact 區塊（導覽列也少了 Contact）。側欄只在 1380px 以上的寬螢幕出現，較窄的螢幕（筆電、平板、手機）改把同一張 Contact 卡放在頁面最後。Experience 底下的「6 roles · 4 organisations · 2 countries」也拿掉了。首頁畫框縮成 155px；寬螢幕上小木屋的畫面高度不超過左側欄（約 710px）。

> 2026-10-01（二）：一進來就看得到完整的小木屋：首頁標題與介紹字縮小、上下留白變少，小木屋的高度跟著視窗剩下的空間走（main.js `fitRoom`，最小 360px，寬螢幕仍不超過左側欄）。1920×962 的視窗整張圖都在第一屏；很矮的筆電螢幕（高度 720px 以下）還是會切到一點。介紹改成研究興趣（電腦視覺、感測、醫療器材）。修一個偶發錯誤：動畫時鐘改用 performance.now()，和手勢、走路的起始時間同一個時鐘（原本用畫格時間，網頁忙時會落後，手勢會查到第一格之前的姿勢而出錯）。

> 2026-10-01（三）：介紹只寫研究興趣（不寫學歷）。拿掉介紹下的「NOW」那一行，空出來的高度給小木屋。小木屋和專案裡的房間特寫不再有藍色天空底框，直接放在頁面背景上，像一座立體模型；側欄的小縮圖保留底色。

> 2026-10-01（四）：屋頂的煙囪改到二樓後牆後面、從牆頂長出來（原本有一截穿進 mmWave 實驗室、浮在牆上，還蓋住海報一角）。MRI 實驗室的磁場警告牌從角落石柱後面移出來，改成有厚度的牌子（旁邊的 k-space 海報往右移一點）。

> 2026-10-01（五）：首頁畫框不再閃：畫框改成三層（底下一張不動的影子、中間只換背景位置的長條圖、上面燈光的 svg，不用混合模式），換一格只重畫中間那層；原本用 svg `<use>` 指到另一個 svg 裡的圖、每次改 viewBox 就連同模糊、混合和陰影一起重畫，有些瀏覽器（Safari）會閃白。嚼餅乾的嘴巴改成 0.32 秒一次。

> 2026-10-01（六）：依審閱意見調整。所有專案統一成「左邊小張房間圖、右邊文字」（Projects 區塊從約 3700px 縮到約 2700px）。「Academic」改名「Course Projects」。進行中的工作用現在式、結束的用過去式；日期寫 Sep；mmWave 的 phantoms 不再重複；小木屋描述的 tumour 改成 tumor。長庚的兩筆研究助理合併成一筆。側欄用短名稱（專案 `short`、單位 `orgShort`），不再被截斷。手機：導覽列換行全部看得到、頭像縮小放在名字旁邊、整座小木屋縮到螢幕寬（About 從約 1500px 提前到約 1000px）。

> 2026-10-01（七）：咖啡店玻璃櫃前排放了一盤布朗尼（四塊、疊兩層）。排第一的客人走到櫃台時會點餐（「one brownie, please!」等，content.js `q1.order`），1.6 秒後咖啡師回答（`barista.serve`）。頂端列只跨中間欄，名字和介紹左緣對齊。樣式表和程式加上內容雜湊版本（`node check.mjs --stamp`），避免瀏覽器把新頁面配到舊的快取樣式。

> 2026-10-01（八）：咖啡店的客人會來來去去（cabin.js「the café's customers come and go」，設定在 `CAFE`）：八位客人從店門前的路邊（畫面下緣）走進畫面，排到隊伍最後，隊伍會一個一個往前；排第一的進店到櫃台點餐（content.js `cafe.order`，咖啡師回 `cafe.serve`），再找空位坐下看書、用筆電、滑手機或喝咖啡（六個座位：窗邊長沙發兩個、四人桌的兩張椅子、兩人桌一張、吧台高腳椅一張），坐 30–60 秒後起身出門，走下路邊淡出畫面，過一陣子再以新客人出現。偶爾有路人只是經過，隊伍太長時會說「the line's too long!」離開。卡在門口互等時會先讓到旁邊。新增坐姿：看書、滑手機、打字。專案區的標題欄縮成 140px，圖和文字間距 40px。

> 2026-10-01（九）：整條人行道打通：路燈和郵筒移到路邊石上、樹移到牆角、花台和長椅前也能走，人可以一路走到最左邊（小狗那裡）並從畫面左端走出去／走進來；咖啡店門前的路邊也還是出入口。配件：後背包（正面看得到一角和肩帶、背面整個包）、小手提包、手上拿的書、寬簷帽。有後背包的客人可以坐窗邊有筆電的位子：先彎身從包包拿出筆電、走前再收回去（桌上的筆電只在那時出現）。新增散步的人：戴寬簷帽的貴婦牽著白色小狗 Coco、一家三口（媽媽、縮小畫的小孩、爸爸），一個接一個跟著走（每個人走進前面那人剛離開的格子），在咖啡店前停一下看看再從另一端離開；同一時間只有一組在外面散步。走不過去時：一組人有優先權，其他人先讓開；帶隊的人等太久也會讓開或在旁邊停下。

> 2026-10-01（十）：人行道兩端各有兩格可以進出（樹移到路邊石轉角），要離開的人走到端點旁邊就可以淡出，不用一定站上那一格，左端不再塞一堆人。客廳拿掉跳舞的人。頭髮從背面看不再是平平切齊的「ㄇ」字：短髮的髮際線在後頸中間往下收、有幾撮髮尾；長髮、鮑伯頭、雙馬尾、辮子、馬尾從背面各自垂下來。保險機制：在外面走動的人（客人或散步的一組）卡住 20 秒會在原地淡出，稍後換成新的人回來（若是要去點餐的人，下一位接著進去）。

> 2026-10-01（十一）：建材更真實。木地板：木板之間色差更大、每塊有深淺兩條木紋、偶爾有帶年輪的木節。牆上木板：木紋更明顯、多一條亮紋。石頭（壁爐、柱子、煙囪、樓梯牆）：每塊寬度不同、有冷暖色差、表面有斑點顆粒、偶爾有細裂縫和缺角、灰縫更深。地毯：加上編織紋理、邊框內一圈小菱形、中間被踩得比較淡。

> 2026-10-01（十二）：咖啡店更豐富（參考使用者給的溫暖咖啡廳圖，自己畫、不用 Habbo 素材）：橫樑下掛一串串暖色燈泡纏著藤蔓、兩盆從樑上垂下的常春藤、桌子上方的裸燈泡吊燈；吧台上有玻璃罩蛋糕、餅乾罐，玻璃櫃裡有三層蛋糕架和三種蛋糕切片（布朗尼還在）；三個座位區各鋪一張地毯，椅子換成青綠色絲絨；桌上有花和蛋糕；臨街矮牆上一排花箱，常春藤垂到人行道那一側。都放在牆、樑、檯面、矮牆或本來就擋住的格子上，客人的路線和座位不變。修正一個舊問題：家具合併成圖片時，裡面的小道具（花、盆栽、木柴、花瓶）因為標籤寫法不同而沒被換成圖，從「Much lighter on the CPU」之後一直沒畫出來，現在都回來了。

> 2026-10-01（十三）：電腦相關的房間更豐富（參考使用者給的電競／駭客房間圖，自己畫）：駭客房的桌子改成玻璃桌面、桌下紫色燈光、桌上喇叭，桌子上方吊一盞發光的魔術方塊燈，旁邊紅色垃圾桶裝滿紙團、地上一組汽水瓶、懶骨頭下一張紫色絨毛圓地毯；伺服器房加一個深色高櫃，放滿霓虹色書背的遊戲和小公仔，桌上檯燈和喇叭；資安室檔案櫃上放一個有魚和水草的魚缸、桌子改玻璃桌面、喇叭和檯燈、一盞魔術方塊燈和一張淺藍絨毛地毯。都放在桌上、櫃上、天花板或本來就擋住的格子，Sam 和貓走動的路線不變。

> 2026-10-01（十四）：人行道加寬成三排（地面從 15 格深變 16 格，練習場也多一排草地，整張圖從 576×480 變 592×488）。排隊的人站中間那排，靠店的一排和靠路邊的一排都能走；路燈、郵筒、Snow girl、樹移到新的路邊石上，出入口跟著移到新路邊。

> 2026-10-01（十五）：對話泡泡改成像追蹤器標籤的樣式：半透明深色底（74%，後面輕微模糊）、細的綠色邊、方角、mono 字體，說話者名字用追蹤綠；太長會換行（最寬 230px）；停留 3.2 秒。同時最多兩個隨機對話（點人物一定會回答）；新泡泡如果會蓋到別的泡泡，就往上移開。專案的 Details 只放文字，乳房攝影的流程圖改成一行文字。

## 非目標

中文版、CV 下載、電話號碼、真實照片、後端或表單、CMS、analytics、build 流程、可拖曳視窗、點家具導覽。

## 技術

純 HTML / CSS / JS，無 build、無 npm dependency。

| 檔案 | 負責 |
| --- | --- |
| `index.html` | 頁面骨架：左欄面板容器、右側欄、footer |
| `style.css` | 2001 Habbo 官網風格：面板、側邊直式標籤、3D 斜角邊、側欄、手機版 |
| `content.js` | **所有文字、連結、NPC 台詞**。之後更新內容只改這個檔 |
| `sprites.js` | 像素 sprite 定義（字元格 → SVG `<rect>`）：avatar、NPC、道具、專案小圖示 |
| `cabin.js` | 小木屋全景與各房間特寫、NPC 動畫與對話泡泡、咖啡人走動 |
| `main.js` | 由 content 產生各面板與側欄 |
| `assets/` | 從 repo 複製來的圖：Breast Cancer `workflow.png` |

字體：內文用 Verdana（原站字體，系統內建）；logo、招牌用 Google Fonts **Silkscreen**（`&` 與數字由 Pixelify Sans 子集補上）。

## 視覺（依原站）

- 頁面底色 `#424242`；面板 `#262626`、灰字 `#adadad`；連結白色粗體底線、結尾 `>>`。
- 每個面板左側一條灰色直式標籤（文字由下往上），右側與下方有斜角的 3D 厚邊。
- 右側欄黑底：小 logo、Latest news、區塊連結、「Guests in Jen's cabin: 13」各房間人數（咖啡人換房間時即時更新；房名連到專案）、聯絡連結；桌機時 sticky。
- 首頁面板：像素房間插圖（2x）+ 橘色立體字 **JEN LI KAO** logo + 斜掛的「INTRODUCING!」招牌 + 黃色圓形「Let's GO」按鈕（連到 Projects）。只用 Habbo 的風格，不用 Habbo 的 logo、名稱或圖片。
- Avatar（依 me.jpeg 畫，照片本身不上傳）：黑色長捲髮、圓框墨鏡、深藍針織毛衣、淺色牛仔褲、軍綠腰包。
- 保留的參考站元件：heyclicky 的 kaomoji 與「Hello my name is」貼紙、contentarchitecture 的 `001` 編號列表 + `TOTAL` 行、側欄連結逐字翻動 hover。

## 動作順暢、人物多樣、兩側卡片（2026-09-27）

- 人物上下浮動：舊的鴨子 CSS `.bob` 動畫剛好套到每個人物的圖層群組上；已刪除並改名，測試確認沒有 CSS 動畫會移動人物（走格子的過渡除外）。

## 人物照 Habbo 的方式動（2026-09-25：使用者回饋「人物會莫名閃爍、動作生硬」，要求上網查 Habbo 人物）

查到的 Habbo 做法（開源客戶端 Nitro 的原始碼，`AvatarVisualization.ts`、`AvatarLogic.ts`、`MovingObjectLogic.ts`）：
- 每 41 ms 更新一次，人物動畫每 2 次更新換一格（約 82 ms 一格）。
- 走一格 500 ms，直線移動。
- 眨眼每 4.5–5.5 秒一次，閉眼 50–250 ms；說話時嘴巴動的時間約「字數 × 1 秒」，中間有短暫停頓；手勢維持 3 秒。
- 人物由分開的部位組成，頭有自己的方向（head direction），可以跟身體不同向。（「別人說話時附近的人會轉頭看」是記憶中的 Habbo 行為，原始碼裡沒找到，屬推測。）

閃爍的原因與修正：
- 原因：每一格是一張各自的圖，用透明度輪流切換；沒顯示過的圖第一次出現時可能還沒解碼，會空一下，兩格切換的瞬間也可能同時都不顯示。
- 修正：每個人的所有畫格放進同一張長條圖（sprite strip），換格只是移動顯示的窗口，不需要載入新圖；完整的長條圖在背景解碼完才換上。壁爐的火也改成長條圖滑動。測試會檢查畫面上每張圖都已解碼。

動作：
- 人物分成身體、頭、手舉到頭前面的部分三層；頭可以單獨轉向。
- 動畫由 JS 每 80 ms 選格：走路 4 格 × 125 ms（走一格剛好一個循環）、打字 150 ms 一格、舞步 260 ms。
- 眨眼、說話的嘴、揮手 3 秒都照 Habbo 的時間；有人說話時，5 格內的人會轉頭看說話的人，平常也會偶爾轉頭看旁邊。
- 閒逛的人（喝咖啡的人、貓、狗）改成像玩家一樣：選 2–6 格外的地點，一路不停走過去，再停一會兒。
- 路線上的工作點不讓閒逛的人站上去，避免互相卡住；被擋太久就放棄這趟。

- 所有牆改成**原木牆**：一根根橫放的圓木（上亮下暗、深色縫、錯開的接縫與木節），牆端露出圓木年輪；每個房間用不同木色（蜂蜜、琥珀、胡桃、深色、淺松木），取代第七次的素色灰泥。
- 樓層邊緣改成**木欄杆**（立柱、扶手、密排欄杆柱）；客廳壁爐與屋頂煙囪改成石砌，煙囪會冒煙。
- 建築後方加兩片「背景板」（x = -0.25、y = -0.25 兩個平面）：遠近兩層雪頂山脈，前面沿建築輪廓排兩排松樹。
- 小道具（植物、樹、攝影機、實驗器材、動物、招牌、雲）全部改成 1px 精度、黑色外框的像素圖（`props.js`，用和人物相同的點陣繪製器），舊的 2px sprite 系統（`sprites.js`）移除。

## 畫素比例（2026-09-24 第七次改版：對照使用者提供的 Habbo VIP 房間截圖）

- 地板格 64×32 px、牆高約 116 px 已和 Habbo 相同；人物縮到 Habbo 房內的大小：**34×64 px（約一格高）**。身體形狀在 44×86 設計格上定義、以 K = 64/86 取樣；臉（眉、眼、鼻、嘴）與墨鏡、眼鏡、護目鏡在最終像素上逐點放置。

## 畫質（2026-09-24 第六次改版：依官方 Habbo 美術做法）

參考：Habbo 官方部落格〈Behind the Pixels〉的家具繪製流程（黑色外框當骨架、光從左上到右下、每種材質用一小段深到淺的色階、桌面的直向亮帶）與 habbo-imaging 產生的官方人物圖（三分之四視角、約 1.4 格高、1px 細節）。

- **人物**（`avatar.js`）：程式逐像素畫出 44×86 px、三分之四視角（面向右下）；每個部位黑色 1px 外框（部位之間自然形成黑色分隔線）、3–4 階色（左上亮、右下暗）；眼白＋大瞳孔＋睫毛線、眉毛、鼻影、微笑線、耳朵、腮紅；髮型（長捲、鮑伯、刺蝟、包頭、捲髮、棒球帽、兜帽）、上衣（T 恤、針織毛衣、帽 T、實驗袍、圍裙、球衣）、褲子、鞋子、配件（圓墨鏡、眼鏡、腰包、論文、咖啡杯、護目鏡）；姿勢：站、走（兩格）、坐、雙手舉起。投手的骨架直接用人物的關節座標畫。
- **家具**：黑色 1px 外框、側面改成硬邊色帶、桌面加亮帶；依顏色自動套材質：木紋、金屬亮條、布料織紋、玻璃反光。咖啡廳客人坐在吧台椅上。
- **驗證**：`tests/`（瀏覽器測試、截圖工具，用本機 Chrome，無 npm 套件）。

## 建築（2026-09-24 第五次改版：多樓層）
