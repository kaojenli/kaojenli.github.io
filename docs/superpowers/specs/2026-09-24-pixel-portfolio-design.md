# Jen Li Kao Pixel Portfolio — Design Spec

日期：2026-09-24　狀態：待 review

## 目標

- 版面仿 **2001 年 Habbo Hotel 官網**（habbohotel.co.uk，2001-09 Wayback 存檔）：深灰底、置中、左欄堆疊面板 + 右側黑色側欄。畫風是 Habbo 像素風；**操作是一般網站**（捲動 + 錨點連結），不做遊戲式互動。
- 招募者在側欄一次看到所有區塊連結。
- 靜態網站，部署在 `https://kaojenli.github.io`。

> 2026-09-24 改版：原本「點房間家具開可拖曳視窗」的設計，依使用者回饋改成上述網站版面；房間保留為首頁插圖。

## 非目標

中文版、CV 下載、電話號碼、真實照片、後端或表單、CMS、analytics、build 流程、可拖曳視窗、點家具導覽。

純 HTML / CSS / JS，無 build、無 npm dependency。

## 人物照 Habbo 實際比例重畫（2026-09-27：使用者「habbo 的人物感還是沒抓對」，附 Habbo 截圖）

量測方式：Habbo 官方的頭像服務擋掉程式下載（防機器人），改用開源專案 HabboHTML5 公開的 Habbo 人物零件（標準站姿、方向 2）與其位置表，組合後量測；零件只放在暫存資料夾量尺寸，網站上沒有用到 Habbo 的圖。

量到的 Habbo 人物（地板格 64×32）：
- 整個人 30×81 px，高而瘦；頭 26×31（約佔身高 38%），平頭頂、正面較平、有下巴，耳朵在後側。
- 臉在頭的前側：眼睛很小（約 3×4，瞳孔在面向的那一側，遠的那隻眼睛稍高），鼻子是一條「>」線，嘴巴是一條短線；頭上幾乎沒有陰影、沒有腮紅。
- 每個零件都是黑色外框，只有 2–3 個色調；身體背面那側在陰影、面向的那側亮（和我原本相反）。
- 身體像立體盒子：衣服下擺是 V 字形（等角盒子的底邊），明暗分界在盒子的轉角；手臂細、直直垂下；鞋子扁長。

改法：人物畫布改成 32×84（原本 34×64，矮胖），直接用像素座標畫（K = 1）；重畫頭、臉、髮型、盒狀上衣與 V 下擺、長腿、扁長鞋、細手臂；所有姿勢重新定位。背影不畫口袋、鈕扣等正面細節。

## 人物照 Habbo 的方式動（2026-09-25：使用者回饋「人物會莫名閃爍、動作生硬」，要求上網查 Habbo 人物）

查到的 Habbo 做法（開源客戶端 Nitro 的原始碼，`AvatarVisualization.ts`、`AvatarLogic.ts`、`MovingObjectLogic.ts`）：
- 每 41 ms 更新一次，人物動畫每 2 次更新換一格（約 82 ms 一格）。
- 走一格 500 ms，直線移動。
- 眨眼每 4.5–5.5 秒一次，閉眼 50–250 ms；說話時嘴巴動的時間約「字數 × 1 秒」，中間有短暫停頓；手勢維持 3 秒。
- 人物由分開的部位組成，頭有自己的方向（head direction），可以跟身體不同向。（「別人說話時附近的人會轉頭看」是記憶中的 Habbo 行為，原始碼裡沒找到，屬推測。）

閃爍的原因與修正：
- 原因：每一格是一張各自的圖，用透明度輪流切換；沒顯示過的圖第一次出現時可能還沒解碼，會空一下，兩格切換的瞬間也可能同時都不顯示。
- 修正：每個人的所有畫格放進同一張長條圖（sprite strip），換格只是移動顯示的窗口，不需要載入新圖；完整的長條圖在背景解碼完才換上。壁爐的火也改成長條圖滑動。測試會檢查畫面上每張圖都已解碼。

動作：
- 人物分成身體、頭、手舉到頭前面的部分三層；頭可以單獨轉向。
- 動畫由 JS 每 80 ms 選格：走路 4 格 × 125 ms（走一格剛好一個循環）、打字 150 ms 一格、舞步 260 ms。
- 眨眼、說話的嘴、揮手 3 秒都照 Habbo 的時間；有人說話時，5 格內的人會轉頭看說話的人，平常也會偶爾轉頭看旁邊。
- 閒逛的人（喝咖啡的人、貓、狗）改成像玩家一樣：選 2–6 格外的地點，一路不停走過去，再停一會兒。
- 路線上的工作點不讓閒逛的人站上去，避免互相卡住；被擋太久就放棄這趟。

## 人物活起來（2026-09-25：使用者回饋「大家都呆站在那裡」）

- 有路線的人（`ROUTES`）：在幾個工作點之間沿最短的空路徑走（BFS），到了面向該做的事、做一陣子再走下一站。咖啡師在義式咖啡機（背對我們在做咖啡）和櫃檯（面向客人出餐）之間來回；排第一的客人從門口走進咖啡廳到櫃檯點餐，再走回門口排隊（追蹤框跟著他）；實驗室的小鼠研究員在鼠籠和控制台之間來回。走過門口時會在室內與室外的圖層之間切換。
- 面向工作：在電腦前的人（駭客、資安分析師、雷達研究員、做假體的研究員）背對我們、面向螢幕打字（兩格輪流）；MRI 技師面向機器；排隊的人面向門口；坐著的客人和讀書的學生面向沙發朝的方向。
- 東張西望：站著或坐著的人不時轉向另一邊看一下。
- 說話時會比手勢（泡泡出現時），被點到會轉過來揮手。
- 新姿勢：打字兩格、說話手勢兩格、站著喝咖啡。

## 房子材質的立體感、專業咖啡機（2026-09-25：使用者回饋「房子的材質還是很 2D」）

- 牆板：每片木板顏色略有不同，左邊亮、右邊暗的倒角，板間暗縫，木紋、偶爾的木節與接縫，上下釘子；護牆板的面板中間凸起且較亮，框架有木紋。
- 木地板：每格 4 條木板，每條顏色不同，錯開的接縫，亮邊與暗縫，木紋與木節。磁磚與戶外石板：每塊有亮的上緣、暗的下緣與填縫。石頭（柱子、樓梯、壁爐、煙囪、外牆底）：每塊有亮的上／左緣與暗的下／右緣，嵌在凹進去的灰縫裡。欄杆柱改成車削的形狀；矮隔間的面板有木紋；地基側面是有石頭的泥土。
- 材質變化用固定雜湊（`hsh`），不影響家具的隨機顏色。
- 咖啡廳後櫃檯換成大台專業雙孔義式咖啡機（不鏽鋼機身、紅色側板、上方溫杯架放著杯子、兩個沖煮頭與把手朝外的沖煮把手、壓力錶、按鈕、凹進去的滴水盤區放著杯子、蒸汽管與牛奶壺，蒸汽從蒸汽管冒出），旁邊是磨豆機；中島上原本的小咖啡機換成小費罐；吊燈降低掛在中島上方，吊櫃縮短讓出咖啡機上方的牆面。

## 物件規格（2026-09-25：以壁爐為標準，檢查所有物件）

每個物件都要符合壁爐的做法（`furni.js` 開頭的共用工具）：

1. **開口要真的凹進去**（`hole` / `basin`）：看得到較遠的內側壁與底面，後面較暗，開口上緣有陰影，裡面的東西以立體物件擺在裡面。
2. **圓的東西是圓柱**（`disc`、`cup3`、`logs` 精靈圖）：有橢圓的頂面或切面，不用方塊代替。
3. **凸出的東西有厚度**（`slab3`、`stud`、`knob`、`pull`）：把手、旋鈕、鏡頭、轉盤都要凸出面板。
4. **內容物是放進去的立體物件**，不是畫在表面上。

這次檢查後修正的物件：
- **做成凹槽**：書櫃每層、MRI 的孔、水槽、咖啡機的出杯區、伺服器機櫃、飲料冷藏櫃、窗戶（玻璃退進牆裡，看得到窗框側面與內窗台，窗格條在玻璃那一層）。
- **做成圓柱**：所有咖啡杯（有杯碟、咖啡、把手）、壁爐旁的柴堆。
- **做成凸出**：冰箱把手、櫥櫃旋鈕與抽屜拉手、書桌抽屜拉手、攝影機鏡頭、保險箱轉盤與把手、檔案櫃把手。

已經符合規格、不需要改的：座椅、桌子、燈、地毯、植物、實驗器材、畫框、壁架。

## 人物更細、動作更自然（2026-09-25：使用者回饋「人物動作僵硬、細節要更細」；「壁爐的火和蠟燭還是 2D」）

- 畫法：部件的內側輪廓改用各自顏色的深色，只有外輪廓是黑色；手臂有手肘、袖口、手指線；腰帶與皮帶扣、褲子摺線、鞋底與鞋帶；眼睛有虹膜顏色和反光、較粗的眉毛、腮紅；外套有翻領。背面（走遠時）頭髮蓋住整顆頭。
- 動作：走路 4 格（身體在換步時抬高 1px），往哪走就面向哪（往畫面上方走看到背面，往左鏡像）；投手 4 格（準備、抬腿、手臂後拉、出手，每格有對應的骨架），球在出手格飛出；舞者 4 格；每個人偶爾眨眼；說話時嘴巴會動；點人物會揮手（坐著的舉手）；閒置小動作：咖啡師伸手拿東西、客人喝咖啡、排隊的人換腳或看手機、實驗室的人伸手或托下巴。
- 效能：場景先只畫每個人的第一格，其他格、眨眼與說話的覆蓋圖在頁面出現後分批補上；揮手的格子第一次點擊時才畫；所有格子的切換對齊 0.4 秒的節拍，減少重繪。
- 壁爐改成往石頭裡凹的爐膛（內側牆、灰燼與餘火、木柴、火焰），蠟燭、書堆、筆電、信箱、攝影機、感測器、畫架、燈籠、柴堆改成立體物件；盆栽、杯子、花瓶、檯燈、燒杯改成有橢圓開口的 3/4 視角；機器人、貓、狗轉向觀看者。
- 修正：上層的靜態圖片不再擋住一樓人物的點擊；裝飾（光暈、攝影機視野、追蹤框、骨架）不接收點擊。
